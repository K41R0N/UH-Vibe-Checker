# Changelog

## [V2.0.0] - 2024-03-XX

### Added
- Comprehensive city data from WikiTravel
- Enhanced city pages with detailed sections:
  - Getting Around (public transport, taxis, cycling, walking)
  - Practical Information (visa, language, currency)
  - Seasonal Information
  - Best Time to Visit
- City configuration system for better data management
- Support for multiple data sources
- Improved SEO metadata
- Static data generation pipeline

### Changed
- Moved from API-based to static JSON data source
- Improved error handling and fallbacks
- Enhanced city page layout and organization
- Updated city card design on homepage
- Streamlined data structure for better maintainability

### Removed
- Unused API integrations
- Unnecessary database configurations
- Redundant data fetching services

### Technical Improvements
- Implemented static site generation for better performance
- Added TypeScript interfaces for all data structures
- Improved build process
- Enhanced development workflow

## [V1.0.0] - 2024-03-XX

### Initial Release
- Basic city information display
- Cost of living metrics
- Quality of life indicators
- Weather information
- Simple routing system
